## 2. FastAPI Backend Deployment (One-Click Options)

### Option A: Render (Recommended & Free Tier Available)
1. Sign up / Log in to [Render](https://render.com).
2. Click **New +** -> **Blueprint**.
3. Connect your GitHub repository (`medipredict-ai`).
4. Render will automatically detect [`render.yaml`](../render.yaml) at the repository root and provision:
   - **`medipredict-backend`**: Python 3.11 Web Service running FastAPI.
   - **`medipredict-postgres`**: Managed PostgreSQL database.
5. Click **Apply**.
6. Once deployed, copy your backend service URL (e.g., `https://medipredict-backend.onrender.com`) and paste it into Vercel's `BACKEND_URL` environment variable.

### Option B: Railway
1. Sign up / Log in to [Railway](https://railway.app).
2. Click **New Project** -> **Deploy from GitHub repo**.
3. Select `medipredict-ai`.
4. Railway will automatically detect [`railway.json`](../railway.json) and [`backend/Dockerfile`](../backend/Dockerfile).
5. Add a PostgreSQL database service in the Railway canvas.
6. Set the environment variables:
   - `ENVIRONMENT`: `production`
   - `DATABASE_URL`: `${{Postgres.DATABASE_URL}}`
   - `SECRET_KEY`: *(generate a random 64-char hex key)*
   - `BACKEND_CORS_ORIGINS`: `https://medipredict-k2upabmcy-ranjeet7680s-projects.vercel.app`
7. Copy the public domain generated by Railway and set it as `BACKEND_URL` on Vercel.

### Option C: Google Cloud Run / Docker
Use the production Dockerfile at [`backend/Dockerfile`](../backend/Dockerfile):
```bash
docker build -t gcr.io/[PROJECT_ID]/medipredict-backend:latest ./backend
docker push gcr.io/[PROJECT_ID]/medipredict-backend:latest
gcloud run deploy medipredict-backend \
  --image gcr.io/[PROJECT_ID]/medipredict-backend:latest \
  --platform managed \
  --allow-unauthenticated \
  --set-env-vars ENVIRONMENT=production,DATABASE_URL=[POSTGRES_URL]
```
